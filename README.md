# 🚗 Climb Rush

**Climb Rush** is a mobile car climbing game developed using Unreal Engine 5. Inspired by games like *Hill Climb Racing*, the game focuses on fun physics-based vehicle control over steep platforms and rugged terrain.

---

## 🎮 Gameplay

- Choose from multiple unique vehicles: sports cars, mini cars, SUVs.
- Customize your car's color in the **Car Paint Garage**.
- Every car has distinct stats — speed, power, suspension, and more.
- Navigate hill-like tracks and survive through tricky climbs.
- More features and maps coming soon!

---

## 🛠️ Built With

- **Unreal Engine 5** (Blueprint scripting)
- Target Platform: **Android**
- Optimized for low-range mobile devices
